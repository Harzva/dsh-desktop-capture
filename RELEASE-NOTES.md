# Host API 1 plugin release

Capture 0.3.1 and terminal 0.2.1 run in separate worker processes and support independent updates and rollback on OpenBot 1.0. The signed catalog includes capture 0.3.0 and terminal 0.2.0 for explicit rollback. The new versions normalize full-width text in search.

No camera PiP, parallel recording or selectable frame rate/resolution is claimed. Previous optional narrated-export and target-close evidence limitations remain. macOS arm64 native helpers are ad-hoc signed, not notarized.

Terminal source is in extensions/superterminal; both archives are distributed in this repository release.
