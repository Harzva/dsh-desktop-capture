# Install

Use OpenBot 1.0 Host API 1: Settings → App connections → Desktop plugins. Review the signed version and capabilities, install, then explicitly enable. Capture 0.3.x and SuperTerminal 0.2.x use this new host. OpenBot 0.14.4 users must keep capture 0.2.2 until the host upgrade. Original media/settings are retained; legacy code is never loaded by Host API 1.

The signed release catalog also provides compatible previous versions for explicit rollback. Stop active recording or terminals before changing their plugin version.
